## 仓库内容

这是作品集网页的可独立部署 HTML 版本：

- `index.html`：作品集首页
- `projects/`：五个项目的独立案例页面
- `styles.css`：完整视觉样式
- `vercel.json`：Vercel 路由配置
- `404.html`：静态站点回退页面

源码不依赖构建工具，可直接打开 `index.html` 预览，也可以部署到 Vercel、Netlify 或任意静态托管服务。

03
问题

桥接位置拥有更多异质接触，但接触机会是否会自动兑现为收益？同时，LLM 行为看似像人，并不意味着它真的在进行可信的社会推理。

产品判断

把“结构带来回报”改写为一条可检验的转化链：结构先提供接触机会，信任校准、互惠回报与关系维持再决定这些机会能否稳定成为社会资本。

RESEARCH CONTROLS / 06

让结果可信，
先让比较成立。

01

随机结构赋位

桥接型、闭合型与边缘型位置随机分配，并在实验前检验属性平衡与网络操纵，避免把 Agent 本身差异误当作结构效应。

02

三类行为基线

LLM、Rule 与 Random Agent 在同一任务下比较，辨认语言表现、规则决策和随机选择各自解释了多少结果。

03

机制消融

依次移除信任学习、关系记忆，并加入机械结构机会基线，定位机会在哪一步被保留、放大或损耗。

04

过程而非终点

同时记录伙伴多样性、跨群体互动、稳定关系与后期收益，让“接触—稳定—回报”的断点可见。

RESEARCH DECISIONS / 07

关键不在于
还能增加什么，
而在于选择什么。

01 / IDENTIFICATION

先证明位置，而不是能力

用随机赋位与处理前检验建立因果识别起点，明确桥接型 Agent 得到的是结构机会，不是预设的高能力。

02 / BASELINE

不给拟人化表现加分

让 LLM 同时面对规则与随机参照；只有超出基线且跨条件稳定的差异，才可能被解释为模型能力。

03 / LIMITS

把不确定性写进结论

两组随机种子只支持探索性发现。页面展示置信区间与未获支持的假设，不把漂亮的模拟包装成确定事实。

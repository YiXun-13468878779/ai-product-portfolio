Memory UX · Privacy · Transparency · AI Governance

02
问题

AI 越了解用户，帮助越个性化；但记住了什么、何时被调用、能否真正删除，往往不可见。信任因此变成黑箱。

产品判断

记忆不应只是模型能力，也应是一套用户权利。让形成有提示、调用有依据、管理有入口、删除可撤回。

PRODUCT SYSTEM / 02

不是功能清单，
是一套相互支撑的体验。

01

记忆仪表板

用概览、场景、时间线与搜索，让用户快速理解 AI 对自己的认知全貌。

02

可逆的控制

支持单条、批量和按时间清理；删除后进入回收站，降低误操作带来的不安。

03

调用透明度

当 AI 使用过去信息时，显示答案基于哪些记忆，帮助用户校验与修正。

04

差异化隐私

工作、学习、生活等场景可分别设置开关、保留期限与敏感信息策略。

DESIGN DECISIONS / 03

关键不在于
还能增加什么，
而在于选择什么。

01 / LEGIBILITY

先让记忆可见

只有用户能找到并读懂系统记住的内容，后续的编辑和授权才真正成立。

02 / CONTROL

删除不制造新的焦虑

撤销窗口与回收站让操作可逆；永久清空则保持明确、严肃且可验证。

03 / TRUST

在使用时解释依据

透明度不只存在于设置页，而应发生在 AI 每次调用记忆的具体时刻。

MY CONTRIBUTION / 04

我完成了什么

  3. 03建立软删除与回收站机制
  4. 04补充隐私偏好与定期透明度报告
